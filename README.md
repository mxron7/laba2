# Weaver Offlane Meta

Персональная страница Мирона Капустянского, студента ПМИ СП.
Статический сайт на HTML, CSS и JavaScript. Сборка и серверная часть не требуются.

## Файлы
- index.html — разметка и содержимое страницы.
- style.css — оформление и адаптация под мобильные устройства.
- script.js — мобильное меню и кнопка «Ещё один матч?».

## Запуск
Откройте index.html в браузере. Картинки загружаются с внешних сайтов, поэтому нужен интернет.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий weaverofflanemeta.
2. Загрузите распакованные файлы в корень репозитория, не сам ZIP.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Дождитесь публикации. Откройте адрес, показанный в Pages, и проверьте его с другой сети.
5. Только после успешной проверки подключайте собственный домен через Custom domain.

Инструкция по домену: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site
Не изменяйте DNS до настройки домена в GitHub Pages.
