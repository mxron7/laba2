# Weaver Offlane Meta
Персональная страница Мирона Капустянского, студента ПМИ СП.
Статический сайт на HTML, CSS и JavaScript. Сборка и серверная часть не требуются.

## Файлы
- index.html — разметка и содержимое страницы.
- style.css — оформление и адаптация под мобильные устройства.
- script.js — мобильное меню и кнопка «Ещё один матч?».
  
## Изображения
Используются внешние изображения персонажей Dota 2. Права на персонажей и изображения принадлежат их правообладателям.
